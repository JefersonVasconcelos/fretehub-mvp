# FreteHub MVP

Aplicacao web estatica para gestao e cotacao de fretes da Salvador Comercial.

## Objetivo

Este MVP substitui a dependencia inicial do Lovable por um projeto proprio, versionavel no GitHub e pronto para evoluir.

Ele cobre:

- dashboard operacional;
- pedidos;
- simulador/cotacao de frete;
- escolha de transportadora;
- transportadoras;
- tarifas;
- auditoria;
- relatorios basicos;
- persistencia local no navegador.

## Como abrir

Abra o arquivo `https://jefersonvasconcelos.github.io/fretehub-mvp/` no navegador.

Nao ha instalacao, build ou backend nesta primeira versao.

## Como publicar no GitHub Pages

1. Suba esta pasta para um repositorio GitHub publico.
2. No GitHub, acesse `Settings > Pages`.
3. Em `Build and deployment`, selecione:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
4. Salve.
